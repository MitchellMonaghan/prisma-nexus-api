# Scalar Instructions

Parent: [`../AGENTS.md`](../AGENTS.md)

The generator package maintainers own Nexus scalar adapters here. `BigInt.ts`, `Bytes.ts`,
`DateTime.ts`, `Decimal.ts`, and `Json.ts` define individual scalar behavior; `index.ts` owns the
default set and exclusion filtering.

Canonical documentation: [`../../../../../docs/components/generator-package.md`](../../../../../docs/components/generator-package.md).
Verify serialization, parsing, GraphQL names, Nexus method names, and exclusion behavior whenever a
scalar contract changes.
