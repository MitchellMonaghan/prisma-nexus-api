# Query Instructions

Parent: [`../AGENTS.md`](../AGENTS.md)

The generator package maintainers own generated query fields here. `aggregate.ts`, `findCount.ts`,
`findFirst.ts`, `findMany.ts`, and `findUnique.ts` map Nexus resolvers to Prisma operations and
apply model-specific overrides before global overrides; `index.ts` exports them.

Canonical documentation: [`../../../../../docs/components/generator-package.md`](../../../../../docs/components/generator-package.md).
Verify argument construction, context selection, nullability or list shape, operation naming, and
both override levels for changed queries.
