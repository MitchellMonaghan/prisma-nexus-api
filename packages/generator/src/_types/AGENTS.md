# Shared Type Instructions

Parent: [`../AGENTS.md`](../AGENTS.md)

The generator package maintainers own shared API configuration and access-selector types here.
`apiConfig.ts` defines runtime configuration and override options; `genericApiConfig.ts` defines
model operation settings; `genericPropertySelector.ts` defines selector shapes; `index.ts` exports
them. `uniqFields.json` is generated by `prismaGenerator/genApiConfigTypes.ts` and must not be
edited as an independent source of truth.

Canonical documentation: [`../../../../docs/components/generator-package.md`](../../../../docs/components/generator-package.md).
Verify public type changes with the package build and behavior using the affected type consumer.
