# Generator Package Instructions

Parent: [`../AGENTS.md`](../AGENTS.md)

The package maintainers own the published `prisma-nexus-api` library and CLI in this folder.
`package.json` owns package metadata and scripts; `src/` owns implementation; `jest.config.js`,
`.eslintrc.js`, and `tsconfig.json` own verification and compilation configuration. Preserve
`README.md` byte-for-byte unless a separate task explicitly authorizes changing existing docs.

Canonical documentation: [`../../docs/components/generator-package.md`](../../docs/components/generator-package.md)
and [`../../docs/features/schema-to-server.md`](../../docs/features/schema-to-server.md).
Commands declared here are unverified until run: `pnpm test`, `pnpm build`, and `pnpm lint`.
