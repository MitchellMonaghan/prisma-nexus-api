# Local Container Instructions

Parent: [`../AGENTS.md`](../AGENTS.md)

The repository maintainers own local container orchestration here. `.docker/docker-compose.yaml` is
used by the `dockerCompose` script in `packages/usage/package.json`.

Canonical documentation: [`../../../docs/components/usage-application.md`](../../../docs/components/usage-application.md).
Before running or changing the composition, inspect its ports, volumes, credentials, persistence,
and shutdown behavior. The discovered `pnpm dockerCompose` command is unverified.
