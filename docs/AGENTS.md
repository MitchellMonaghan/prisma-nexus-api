## Purpose and ownership

This directory owns maintainer documentation added alongside the preserved project READMEs. It directly owns `README.md` and the `components/` and `features/` children.

Keep all claims grounded in inventoried source. Mark commands unverified unless controlled execution passed. Record missing evidence as a gap. Every document must link to its parent index; every index must list direct child documents and folders. Add a linked table of contents whenever a document has more than one substantive section.

The preserved public overview remains [the root README](../README.md).
