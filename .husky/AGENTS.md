## Purpose and ownership

This directory owns checked-in Husky hooks. It directly owns `commit-msg`.

Keep hooks short, non-interactive, and aligned with the root preparation script and commitlint configuration. If hook behavior changes, document any new local prerequisite.

Relevant references: root `package.json` and `commitlint.config.js`.
